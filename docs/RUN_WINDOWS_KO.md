# Windows 데스크톱에서 실행하기

공고번호를 넣으면 **BEST10 과 최종 추천 사정율(투찰금액·낙찰확률)** 을 화면에 보여 주고 Excel/Markdown 파일로 저장합니다.
매번 전체 데이터를 다시 학습할 필요는 없습니다. 공고 하나를 분석할 때마다 그 공고의 개찰일 **이전** 자료만으로
사정율 분포·경쟁사 모형·예상 업체수를 그 자리에서 계산합니다.

## 1. 준비물

* Windows 10/11
* Python 3.11 (기존 분석 프로그램용으로 이미 설치되어 있으면 그대로 씁니다)
* 데이터: `CBF.xlsx`(시트 `통합데이터`), 복수예가 폴더(발주기관별 xlsx, 파일명 = 발주기관명)

Python 이 있는지 확인: 시작 메뉴에서 `cmd` 를 열고

```
py -3.11 --version
```

`Python 3.11.x` 가 나오면 됩니다. 안 나오면 <https://www.python.org/downloads/> 에서 3.11 을 설치하십시오
(설치 첫 화면에서 **Add python.exe to PATH** 체크).

## 2. 코드 받기

둘 중 하나를 고르십시오.

* GitHub 의 Pull Request #1 을 병합(Merge)한 뒤, 저장소 첫 화면에서 **Code → Download ZIP**
* 병합 전이라면 브랜치 ZIP 을 바로 받기:
  <https://github.com/jisehyun75/mypage/archive/refs/heads/claude/nara-jangter-bidding-prediction-4kbg32.zip>

압축을 풀기 **전에** 받은 ZIP 파일을 오른쪽 클릭 → 속성 → 아래쪽 **차단 해제** 체크 → 확인을 누르십시오
(인터넷에서 받은 파일이라 그대로 풀면 bat 파일 실행 때마다 경고가 뜹니다. 그래도 파란 'Windows의 PC 보호' 창이 뜨면 **추가 정보 → 실행**).

압축을 풀고 폴더 이름을 알기 쉽게 바꿉니다(예: `C:\nara_bid_stat`). 그 폴더 안에
`nara_bid_stat`, `scripts`, `requirements.txt` 가 보여야 합니다.

## 3. 데이터 넣기

```
C:\nara_bid_stat\
    data\CBF.xlsx
    data\prebid\충청북도 청주시.xlsx
    data\prebid\조달청 충북지방조달청.xlsx
    ...
```

* 파일 이름을 바꿀 때 Windows 는 기본으로 확장명(`.xlsx`)을 숨기므로 **`CBF` 까지만** 입력하십시오
  (`CBF.xlsx` 라고 치면 실제 이름이 `CBF.xlsx.xlsx` 가 됩니다. 이 경우도 프로그램이 알아서 찾습니다).
  탐색기 **보기 → 파일 확장명** 을 켜 두면 헷갈리지 않습니다.
* 복수예가 xlsx 파일은 `data\prebid` 폴더 **바로 안에** 둡니다. 폴더 이름을 `data\복수예가` 로 두어도 되고,
  폴더째 한 단계 안에 넣은 경우(`data\prebid\복수예가\*.xlsx`)도 찾아 씁니다.
* 다른 곳에 두고 싶으면 명령에 경로를 직접 쓰거나, 환경변수 `NARA_CBF`(CBF 파일), `NARA_PREBID`(복수예가 폴더)를 지정합니다.
* `data`, `results` 폴더와 xlsx 파일은 GitHub 에 올라가지 않게 설정되어 있습니다.

## 4. 공고 분석하기 (가장 자주 쓰는 기능)

### 더블클릭으로

1. `scripts\ANALYZE.bat` 를 더블클릭합니다. 처음 한 번은 필요한 패키지(numpy, pandas, openpyxl)가 없으면 설치합니다.
2. `Notice number(s)` 가 나오면 공고번호를 입력합니다. 예: `R26BK01740091-000` (여러 개는 띄어쓰기로)
   * `LIST` 를 입력하면 CBF 에 있는 개찰 전 공고 목록이 나옵니다.
   * 그냥 Enter 를 누르면 끝납니다.
3. 결과가 화면에 나오고 `results\analyze\분석_공고번호.xlsx` / `.md` 로 저장됩니다.

바탕 화면에서 실행하고 싶으면 `ANALYZE.bat` 를 옮기지 말고 **오른쪽 클릭 → 보내기 → 바탕 화면(바로 가기 만들기)** 를 쓰십시오
(bat 파일은 `scripts` 폴더 안에 있어야 프로그램을 찾습니다).

화면의 '사정율 분포:' 줄이 `복수예가(` 로 시작하면 그 기관의 복수예가 이력을 쓴 것이고, `이론분포` 로 시작하면 복수예가 파일을
찾지 못해 예가변동폭 이론분포를 쓴 것입니다(±3% 기관은 둘이 같습니다).

### 명령 프롬프트에서

```
cd C:\nara_bid_stat
py -3.11 -m nara_bid_stat analyze --cbf data\CBF.xlsx --prebid-dir data\prebid --notice R26BK01740091-000
py -3.11 -m nara_bid_stat analyze --cbf data\CBF.xlsx --list
```

처음 실행은 CBF·복수예가를 읽느라 시간이 걸립니다(샘플 CBF 기준 약 30초, 전체 CBF 는 더 걸림).
읽은 표는 `C:\Users\사용자\.nara_bid_stat_cache` 에 저장되어 두 번째부터는 몇 초면 됩니다.
CBF 나 복수예가 파일이 바뀌면 자동으로 다시 읽습니다. 공고 하나의 계산은 보통 10 ~ 40초입니다
(경쟁사 모형 대안의 선택 편향 보정 포함, `--n-boot 0` 이면 대안을 생략하고 더 빠름).

### CBF 에 아직 없는 공고

공고문의 값을 직접 넣습니다(cmd 에서 줄을 나눌 때는 `^`).

```
py -3.11 -m nara_bid_stat analyze --cbf data\CBF.xlsx --prebid-dir data\prebid --notice 새공고번호 ^
    --org "충청북도 청주시" --industry 전기 --base 312450000 --lower-rate 89.745 ^
    --a-value 12340000 --net-cost 280000000 --band 3 --date "2026-10-12 11:00"
```

* 반드시 필요: `--org`(복수예가 파일명과 같은 기관명), `--base`(기초금액), `--lower-rate`(하한율 %, 예: 89.745), `--band`(예가변동폭: 3, 2, 2.5), `--date`(개찰일시)
* 기관명이 복수예가·CBF 어디에도 없으면 경고와 함께 비슷한 기관명을 보여 줍니다.
* 있으면 넣기: `--a-value`(A값), `--net-cost`(순공사원가), `--industry`(업종), `--est-price`(추정가격)
* CBF 에 있는 공고라도 같은 옵션을 주면 그 값만 바꿔서 분석합니다(예: 기초금액이 나중에 공개된 경우).

## 5. 화면 출력 읽는 법

```
BEST10 (실제 사정율이 들어갈 확률이 높은 0.1 구간)
    1  -0.1x    [-0.2, -0.1)    4.95%   4.95%
   ...
  -> BEST10 적중확률 47.1%

최종 추천 사정율(투찰용): -0.1033   투찰금액 345,734,736원
  낙찰확률 0.1952% (효율적 시장 기준, 경쟁사 모형 기준 0.2048%) · 무작위 선택 0.1944% · 예상 업체수 408곳
대안(경쟁사 모형, 미검증): -1.5000   투찰금액 340,935,949원
```

* **BEST10**: 실제 사정율이 들어갈 가능성이 높은 0.1 구간 10개와 확률입니다(부호 구분: `-0.1x` = −0.2 ~ −0.1).
  사정율은 복수예가 추첨으로 정해지므로 BEST10 적중확률(±3% 기관 약 47%)보다 잘 맞힐 수는 없습니다.
  어떤 프로그램이 BEST10 을 이보다 훨씬 높게 맞힌다고 하면 과거 자료에 맞춘 결과일 가능성이 큽니다.
* **최종 추천 사정율(투찰용)**: 이 사정율을 가정해 계산한 금액으로 투찰하라는 뜻입니다. '실제 사정율이 이 값이 된다'는 예측이 아니라
  **낙찰확률이 가장 높은 투찰 위치**(사정율 분포의 중앙값)입니다. 실제 사정율이 이 값 이하이면 투찰이 유효합니다.
* **투찰금액**: max(하한가, 순공사원가 × 98% × (1+사정율)), 원 미만 절상. 투찰 전 공고문의 A값·순공사원가를 꼭 확인하십시오.
* **낙찰확률**: 다른 유효 투찰이 있을 때 1순위가 될 확률입니다. 업체수를 모르므로 비슷한 과거 공고의 업체수로 평균했고,
  백테스트에서 합계 기준 약 11% 낮게 나왔으므로 하한 쪽 추정으로 보십시오. 업체가 많으면(수백 곳) 어떤 사정율이든 약 1/업체수입니다.
* **대안(경쟁사 모형)**: ±3% 기관에서 경쟁사가 드문 낮은 사정율 구간입니다. 아직 낙찰 수로 검증되지 않은 가설이므로 참고만 하십시오.
* 이미 개찰된 공고를 넣으면 개찰일 이전 자료로만 분석한 결과와 **실제 결과**(실제 사정율, BEST10 적중, 최종 추천으로 투찰했다면 낙찰 여부)를
  함께 보여 줍니다. 과거 공고 여러 건으로 직접 확인해 보는 데 쓰십시오.

## 6. 전체 점검·보고서 (가끔)

`scripts\RUN_ALL.bat` 를 더블클릭하면 데이터 점검, 시간순 백테스트(수십 분), 개찰 전 전체 공고 보고서를 차례로 만듭니다.

```
results\1_cbf_audit   데이터 품질, 하한가·순공사원가 산식 검증, 경쟁사 모형
results\2_backtest    과거 공고에 같은 방법을 적용한 성적(실제 1순위 금액과 비교)
results\3_consult     개찰 전 공고 전체 보고서(컨설팅_보고서.xlsx / .md)
```

CBF 를 새로 받을 때마다(예: 한 달에 한 번) 돌려서 성적이 유지되는지 확인하는 것을 권합니다.

## 7. 자주 생기는 문제

| 증상 | 해결 |
|---|---|
| `'py'은(는) 내부 또는 외부 명령...` | Python 3.11 설치(PATH 체크). bat 파일은 `py` 가 없으면 `python` 으로 실행합니다 |
| 한글이 깨져 보임 | 명령 프롬프트에서 먼저 `chcp 65001` 실행(bat 파일은 자동) |
| `CBF 파일을 찾을 수 없습니다` | `data\CBF.xlsx` 위치 또는 `--cbf` 경로 확인 |
| `결과 파일을 저장하지 못했습니다` | 같은 이름의 결과 xlsx 가 Excel 에서 열려 있음 → 닫고 다시 실행 |
| `'...' 은(는) CBF 에 없습니다` | 비슷한 번호를 보여 줍니다. 새 공고면 4장의 직접 입력 사용 |
| `공고번호 ... 가 CBF 에 2건 있습니다` | 국방 공고번호는 해마다 재사용됩니다. 개찰 전 건(없으면 가장 최근 건)을 분석합니다 |
| `복수예가 폴더에 xlsx 파일이 없습니다` | 복수예가 xlsx 를 `data\prebid` 바로 안에 두십시오 |
| `[ERROR] The nara_bid_stat folder was not found` | ANALYZE.bat 를 scripts 폴더 밖으로 옮긴 경우. 원래 위치로 되돌리고 바로 가기를 쓰십시오 |
| `[ERROR] Installing numpy, pandas and openpyxl failed` | 인터넷(회사 프록시) 확인 후 다시 실행. 또는 `py -3.11 -m pip install -r requirements.txt` |
| CBF 를 바꿨는데 예전 결과 같음 | 파일 수정시각으로 자동 갱신됩니다. 그래도 이상하면 `--no-cache` 또는 캐시 폴더 삭제 |
| 기관명 불일치로 복수예가를 못 찾음 | 출력의 '사정율 분포' 출처가 '이론분포'로 나옵니다. 복수예가 파일명을 CBF 기관명(또는 뒷부분)과 맞추십시오 |
| 출처 끝에 `[±2 이력 N건뿐이라 전체 이력 사용]` | 그 기관의 복수예가 범위가 공고의 예가변동폭과 다릅니다(국방 등). 결과를 참고만 하십시오 |
