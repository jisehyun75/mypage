# nara_bid_stat — 나라장터 입찰 사정율·낙찰확률 통계 검증 도구

나라장터 적격심사(하한 근접 최저가) 입찰 분석을 **검증 가능한 통계 모델** 위에 올리기 위한 도구입니다.
두 가지 자료를 씁니다.

| 자료 | 내용 | 쓰임 |
|---|---|---|
| 복수예가 폴더 | 발주기관별 Excel(개찰일·기초금액·예정가격·1~15번 예가) | 사정율 **확률분포**(생성 규칙, 4개 추첨) |
| CBF.xlsx `통합데이터` | 공고·하한율·A값·순공사원가·예정가격·**1순위 금액·업체수** | 산식 검증, **경쟁사 분포** 추정, 전략 백테스트, 개찰 전 컨설팅 보고서 |

## 설치

Python 3.11 이상, 외부 패키지는 `numpy`, `pandas`, `openpyxl` 뿐입니다(scipy 불필요).

```bash
pip install -r requirements.txt
python -m unittest discover -s tests      # 89개 테스트(합성 데이터)
```

## 공고 하나 분석 (BEST10 + 최종 추천 사정율)

```bash
python -m nara_bid_stat analyze --cbf CBF.xlsx --prebid-dir 복수예가 --notice R26BK01740091-000
python -m nara_bid_stat analyze --cbf CBF.xlsx --list          # 개찰 전 공고 목록
```

공고번호를 넣으면 그 공고의 개찰일 **이전** 자료만으로 사정율 분포·경쟁사 모형·예상 업체수를 그 자리에서 계산해
**BEST10**(0.1 구간 10개와 확률), **최종 추천 사정율**(투찰용, 사정율 분포 중앙값)과 투찰금액·낙찰확률, 경쟁사 모형 대안을 출력하고
`분석결과/분석_공고번호.xlsx·md` 로 저장합니다. CBF 에 없는 새 공고는 `--org --base --lower-rate --band --date` 로 직접 입력합니다.
이미 개찰된 공고를 넣으면 실제 결과(BEST10 적중, 추천대로 투찰했다면 낙찰 여부)도 함께 보여 줍니다.
읽은 데이터는 캐시되어 두 번째 실행부터 빠릅니다.

**Windows 데스크톱:** `scripts\ANALYZE.bat` 더블클릭 → 공고번호 입력. 설치부터 출력 읽는 법까지는
[docs/RUN_WINDOWS_KO.md](docs/RUN_WINDOWS_KO.md) 를 보십시오.

## 한 번에 실행

```bash
python -m nara_bid_stat run-all --cbf CBF.xlsx --prebid-dir 복수예가 --out 결과
#   결과/1_cbf_audit   데이터 품질·산식 검증·경쟁사 모형
#   결과/2_backtest    시간순 전략 백테스트(수 분 ~ 수십 분, --skip-backtest 로 생략 가능)
#   결과/3_consult     개찰 전 공고 컨설팅 보고서(컨설팅_보고서.xlsx / .md, 대안 보정 부트스트랩 포함 수 분)
```

Windows 에서는 `scripts\RUN_ALL.bat [CBF.xlsx] [복수예가폴더] [출력폴더]` 를 실행하면 됩니다
(기본값 `data\CBF.xlsx`, `data\prebid`, `results`).

## 개별 명령

```bash
# CBF 연동
python -m nara_bid_stat cbf-audit --cbf CBF.xlsx --out cbf_audit
python -m nara_bid_stat backtest  --cbf CBF.xlsx --prebid-dir 복수예가 --start 2025-07-01 --out backtest_out
python -m nara_bid_stat consult   --cbf CBF.xlsx --prebid-dir 복수예가 --backtest backtest_out --out consult_out
python -m nara_bid_stat consult   --cbf CBF.xlsx --notice R26BK01740091-000      # 특정 공고만

# 복수예가만
python -m nara_bid_stat audit    --prebid-dir 복수예가 --out audit_out
python -m nara_bid_stat forecast --prebid-dir 복수예가 --org "충청북도 청주시" --asof 2026-10-01

# 산식·검정 도구
python -m nara_bid_stat bid      --base 312450000 --lower-rate 87.745 --a-value 12340000 --net-cost 280000000 --rate -0.13
python -m nara_bid_stat nulltest --cases 60 --prior 0.44
```

경쟁사 모형의 평활 강도는 `--lam auto`(기본: 학습 구간 안에서 시간순 검증 우도로 선택, 귀무모형 포함) /
`--lam null`(경쟁사 = 자연 사정율 분포) / 숫자로 지정합니다.

## 실데이터로 확인한 사실

자세한 수치와 근거는 [docs/METHODOLOGY_KO.md](docs/METHODOLOGY_KO.md)에 있습니다.

### 복수예가(충북권 66개 기관, 40,971건, 2020-01 ~ 2026-09)

1. **15개 예가는 칸별 균등난수입니다.** ±3% 기관(지자체·교육청)은 음수 8칸 + 양수 7칸, 조달청 등(±2%, ±2.5%)은 15등분입니다.
   국방(D2B)은 거의 고정된 격자, 한전·LH는 자체 규칙이고, LH 일부는 (기초금액−A값) 기준으로 기록됩니다(자동 환산).
2. **4개 선택은 사실상 추첨입니다.** 1365조합 안에서 실제 예정가격의 위치가 균등분포입니다.
3. **사정율 분포는 생성 규칙으로 거의 확정됩니다.** ±3% 규칙 이론 P(양수) 44.8%, 실제 43.9%.
   이력 기반 부호 예측(54.5%)은 '항상 음수'(54.1%)와 같고, 최근 흐름(최근 20건·EWMA·직전값)은 오히려 나쁩니다.
4. **무기술 기준선:** 사정율 분포 상위 0.1 구간만 골라도 BEST10 54.1%, BEST5 28.9%, BEST1 6.0% 입니다.
5. **소표본 자동튜닝은 위험합니다.** 60건·후보 10개·정확도 54% 기준 방식은 정보가 없는 모델로도 57~60% 확률로 통과합니다.

### CBF(전기·통신·소방 3,552건, 2025-01 ~ 2026-10)

6. **산식:** 낙찰하한가는 원 미만 절상, 순공사원가 98% 기준은 **사정율을 곱한** 금액으로 적용됩니다
   (그 기준이 하한가보다 높은 27건 중 26건의 1순위가 사정율 반영 기준을 지켰고, 미반영 기준은 34건 중 12건만 지켰습니다).
   1순위사정율 = min(하한가 역산, 순공사원가 역산)이며, 이렇게 계산하면 완료 공고 3,199건 전부 원본과 일치합니다.
7. **시장은 효율적입니다.** 경쟁사들의 가정 사정율 분포가 자연 사정율 분포와 거의 같습니다
   (2,360건 시간순 백테스트에서 무작위 선택의 실제 낙찰 39.0건 vs 효율적 시장 이론값 38.1건).
8. **효율적 시장에서는 중앙값이 최적입니다.** 1순위가 있는 공고 기준 낙찰확률은 (1−(1−a)^(N+1)−a^(N+1))/N (a=F(x))로
   중앙값에서 최대 (1−2^−N)/N, 무작위 선택은 1/(N+2) 입니다. '무작위 대비 몇 배'는 기술의 증거가 아닙니다.
9. **백테스트(2025-07 ~ 2026-09, 매월 과거 자료로 재학습):** 중앙값 51건(효율적 시장 기대 44.8건), 경쟁사 모형 48건,
   최빈 구간 44건. 경쟁사 모형이 중앙값보다 낫다는 증거는 없고, 이 표본으로 검출 가능한 최소 우위는 약 1.45배입니다.
   구조 모형이 실제로 쓰인 214건(2026-07 이후)에서는 모형이 낙찰 5.0건을 예측했으나 실제 3건(중앙값 6건)이었습니다.
   ±3% 기관의 낮은 사정율 구간에 경쟁사가 적다는 구조(간격 예측 z = 4.2)는 있으나 낙찰 수로는 아직 확인되지 않았습니다.
10. **그래서 컨설팅 보고서의 기본 추천은 중앙값**이고, 경쟁사 모형 추천은 선택 편향을 보정한 '미검증 대안'으로만 표시합니다.
11. **낙찰확률 수치의 불확실성은 대부분 업체수에서 옵니다.** 개찰 전 업체수 표본으로 계산한 효율적 시장 기대 낙찰은
    실제 업체수로 계산한 값보다 약 11% 낮습니다(40.0 vs 44.8건). 업체 2~5곳 공고가 드물고 미리 알기 어렵기 때문이며,
    백테스트 요약의 `n_sampler_vs_actual_ratio` 로 매번 확인합니다.

## 출력: 컨설팅 보고서(`consult`)

공고마다 사정율 분포(출처·평균·P(양수)·50%/80% 구간), 예상 업체수, 경쟁사 모형, **기본 추천(중앙값)과 대안(경쟁사 모형)**의
사정율·투찰금액·낙찰확률을 싣고, 산식 검증·데이터 품질·경쟁사 모형 선택 근거·백테스트를 시트로 함께 냅니다.

* 낙찰확률은 '다른 유효 투찰이 있는 경우'(과거 개찰결과로 검증 가능한 부분) 기준입니다. 경쟁사가 모두 하한 미달이라
  나만 유효해지는 확률은 검증할 수 없어 참고로만 따로 표시합니다.
* 기본 추천과 무작위 선택의 낙찰확률은 **효율적 시장 기준**(기본 추천의 근거와 같은 기준)이고,
  경쟁사 모형 기준 값은 `경쟁사모형_*` 컬럼에 따로 둡니다.
* 대안의 낙찰확률은 **선택 편향을 보정한 값**입니다. 모형 곡선의 최댓값을 고르고 같은 모형으로 읽으면 위로 치우치므로,
  학습 자료를 복원추출해 다시 적합한 모형 30개로 같은 절차를 반복해 과대 배율(실데이터 약 1.03~1.04배)을 재고 나눕니다
  (`--n-boot`, 0 이면 대안 생략). 보정 후 중앙값보다 1% 이상 낫지 않으면 대안을 내지 않습니다.
* 공고의 사정율 분포가 경쟁사 모형의 기준 규칙과 다르면(국방·한전 등) 경쟁사 모형을 쓰지 않고 효율적 시장으로 계산합니다.

## 구성

```
nara_bid_stat/
  mechanism.py    생성 규칙 판별, 1365조합, RateDistribution(예측 분포, 평활)
  data.py         복수예가 Excel 로더(중복 제거, LH 기준 환산)
  cbf.py          CBF 로더·표준화, 데이터 품질, 하한가·순공사원가 산식 검증
  bid.py          통일 투찰 산식, 투찰금액 -> 유효 상한 사정율, 낙찰확률 곡선(결정적 구적), 효율적 시장 공식
  competition.py  1순위 간격 우도로 경쟁사 분포 추정(벌점 최대우도, lambda 자동 선택, 귀무모형), 진단
  strategy.py     공고별 사정율 분포·업체수·추천, 시간순 전략 백테스트와 요약 검정
  consult.py      개찰 전 공고 컨설팅 보고서(Excel/Markdown), 공고별 BEST10·화면 요약
  cache.py        읽은 CBF·복수예가 표 캐시(원본이 바뀌면 자동 갱신)
  scoring.py      CRPS, PIT, 구간적중, Wilson CI, 이항검정, Diebold-Mariano, KS
  walkforward.py  사정율 분포 워크포워드 검증, 기존 엔진 BEST-k 장부 평가(McNemar)
  audit.py        복수예가 데이터 감사, 튜닝 절차 귀무 시뮬레이션
scripts/ANALYZE.bat   Windows: 공고번호 입력 -> BEST10 + 최종 추천 사정율
scripts/RUN_ALL.bat   Windows: 점검 + 백테스트 + 전체 보고서 일괄 실행
tests/                unittest 89개(합성 데이터)
docs/                 방법론과 검증 근거
```

## 주의

* 이 저장소에는 입찰 원본 데이터가 들어 있지 않습니다. 테스트는 합성 데이터로만 동작합니다.
* 투찰금액은 공고문의 A값·순공사원가·하한율 적용 기준을 반드시 확인한 뒤 사용하십시오.
* 사정율과 경쟁사 투찰은 확률변수입니다. 출력은 '정답'이 아니라 보정된 확률이며 낙찰을 보장하지 않습니다.
